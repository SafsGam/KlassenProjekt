Proyecto de clase

Funktion dieser Seite soll es sein, die Daten von PHP zu erhalten und in JSON-Format lesbar zu machen. Nun stelle ich mir die Frage, warum? Warum muss ich PHP in JSON umwandeln? Kann ich nicht direkt mit der PHP-Datei arbeiten?

PHP-Datenstrukturen wie Arrays und Objekte können nicht direkt als lesbare Textdateien gespeichert werden, da sie im Speicher binäre Daten enthalten und keine standardisierte, sprachunabhängige Textrepräsentation besitzen. Um diese Daten persistent zu speichern oder zwischen verschiedenen Systemen (z. B. PHP und JavaScript) auszutauschen, müssen sie serialisiert werden – also in ein einheitliches Textformat wie JSON umgewandelt werden.

JSON dient als ideales Austauschformat, weil es von fast allen Programmiersprachen nativ unterstützt wird und für Menschen mit etwas Übung leicht lesbar und editierbar ist.

Schritt 1. Daten aus der Datenbank (SQL)

Die Daten kommen ursprünglich aus einer Datenbank. SQL-Abfrage:

SELECT * FROM tasks;

Schritt 2. PHP empfängt die Daten als Array

PHP gibt die Daten intern aus. für uns Menschen und für andere Programmiersprachen wie JavaScript kaum lesbar:

Array ( [0] => Array ( [id] => 1 [title] => Erste Aufgabe ) [1] => Array ( [id] => 2 [title] => Zweite Aufgabe ) )

Dieser Output ist weder für Menschen noch für andere Programmiersprachen direkt nutzbar. JavaScript kann damit nichts anfangen.

Noch extremer: PHP's serialize() so sieht es aus wenn PHP Daten intern speichert:

a:2:{i:0;a:2:{s:2:"id";i:1;s:5:"title";s:13:"Erste Aufgabe";}i:1;a:2:{s:2:"id";i:2;s:5:"title";s:14:"Zweite Aufgabe";}}

Nur PHP selbst kann dieses Format lesen, für alle anderen Sprachen völlig unbrauchbar.

Schritt 3. Umwandlung in JSON mit json_encode()

Nach der Umwandlung mit json_encode() sieht das Ergebnis so aus:

[{"id": 1, "title": "Erste Aufgabe"}, {"id": 2, "title": "Zweite Aufgabe"}]

Dieses Format ist für Menschen lesbar und wird von fast allen Programmiersprachen nativ unterstützt auch von JavaScript.

Umwandlung in beide Richtungen

PHP bietet zwei Funktionen um zwischen PHP-Array und JSON zu wechseln:


// PHP Array in JSON umwandeln
$values = ['ersterSchlüssel' => 'ersterWert', 'einBoolean' => true];
$jsonString = json_encode($values);

// JSON String wieder in PHP-Array umwandeln
$data = json_decode($jsonString, true); // true für Array, false/kein 2. Parameter für Objekt

So sieht ca. der Weg der Daten aus: Datenbank → PHP → JSON → HTML → User
