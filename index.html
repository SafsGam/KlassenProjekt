Was ist tx.exe?

tx.exe ist ein Schulprojekt das im Rahmen der Ausbildung zum Fachinformatiker Anwendungsentwicklung entstanden ist. Ziel war es eine kleine Webanwendung zu bauen die verschiedene Kernkonzepte der modernen Webentwicklung verbindet – von der serverseitigen Datenverarbeitung mit PHP über die Kommunikation via JSON bis hin zu einem KI-gestützten Chatbot.

Die Idee dahinter

Der Ausgangspunkt war eine einfache Frage: Wie kommunizieren Frontend und Backend miteinander? Anstatt das nur theoretisch zu beantworten haben wir es direkt gebaut. PHP übernimmt die serverseitige Logik, JSON dient als Austauschformat zwischen den Systemen, und JavaScript verbindet alles im Browser. Als Erweiterung kommt ein Chatbot dazu der über eine externe KI-API (Google Gemini) echte Antworten generiert – womit der Weg von einer simplen Aufgabenliste bis zur KI-Integration sichtbar wird.

Was steckt drin?

Das Projekt besteht aus drei Bereichen: einer Lernseite die den kompletten Datenweg von der Datenbank bis zum Browser erklärt, einer PHP API die Daten als JSON ausgibt, und einem Chatbot der Fragen beantwortet und Textdateien verarbeiten kann. Git wurde durchgehend für die Versionskontrolle genutzt, mit separaten Branches für Frontend und Backend.
